# Privacy policy

Effective date: 21 November 2026

## Who this covers

cowork-gmail-api is a personal-use application operated by Tim Parsons. Its only users are Google accounts owned or administered by the operator. It is not available to the public.

## What data it accesses

With the owner's explicit consent through Google's OAuth flow, the application accesses Gmail message headers, bodies, attachments and labels in the connected accounts, using the `gmail.modify` scope. This allows it to read, search, label, archive and move messages. It cannot permanently delete messages and does not send email autonomously.

## How data is used

Mailbox data is used solely to help the account owner find, summarise and organise their own email. Nothing is used for advertising, profiling or any purpose other than the owner's own email management.

## Where data is stored

OAuth tokens and any working files are stored only on the operator's own computer. No mailbox data is uploaded to any server operated by the application. Where the owner chooses to have messages summarised by a third-party language model, only the content the owner selects is sent for that request, under that provider's own terms.

## Sharing

No mailbox data is sold, rented or shared with any third party.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Revoking access invalidates the stored token immediately.
